# Changelog

All notable changes to Alchyx are documented here. The project follows
[Semantic Versioning](https://semver.org/) while it is in prerelease.

## 0.2.0-beta.1 — Unreleased

### Added

- The full 31-component Alchyx catalog as public React exports.
- React 18 and React 19 consumer verification.
- Native form participation for custom form controls.
- Provider-aware portals and nested overlay coordination.
- Accessible semantic color roles and per-skin accent resolution.
- Accessible syntax-color palettes for Lab, Dark, Ark, and Lembic code surfaces.
- Tailwind CSS 4 CSS-first tokens while retaining the Tailwind 3 preset.

### Changed

- Lab and Dark neutral ramps now follow the current D-ALabs design language.
- Package exports resolve to built ESM, CommonJS, declarations, and CSS.
- Component maturity is evidence-based instead of uniformly marked stable.

### Compatibility

- Existing Button, provider, and token APIs remain available.
- Replaced token helpers are deprecated rather than removed.
- This prerelease is prepared for validation only; publishing requires a
  separate release approval.
